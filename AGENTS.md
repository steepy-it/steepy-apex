# steepy-apex

A plugin for Claude Code, Codex, OpenCode, Pi, and DeepSeek Harness that keeps your project's rules in a versioned hub, checks that its links and code references still resolve, and sizes the workflow to each task.

## Development commands

- `npm test`

## Confirmed surfaces

- `adapters` (`adapters`) — `adapters-agent`
- `scripts` (`scripts`) — `scripts-agent`
- `skills` (`skills`) — `skills-agent`
- `templates` (`templates`) — `templates-agent`
- `tests` (`tests`) — `tests-agent`

## Project navigation

For every task, use the `steepy-apex-bootstrap` skill first. If that skill is unavailable, read `.apex/_INDEX.md` before making changes.
